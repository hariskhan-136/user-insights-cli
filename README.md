# User Insights CLI

A Node.js command-line application that fetches users, posts, and todos from JSONPlaceholder and generates a user insights report.

## Features

- Fetches users, posts, and todos concurrently
- Uses Promise.all()
- Uses async/await
- Uses array methods for data transformation
- Generates user insights
- Sorts users by post count and name
- Displays summary statistics
- Handles API errors

## Requirements

- Node.js
- npm

## Installation

Clone the repository:

git clone https://github.com/hariskhan-136/user-insights-cli.git

Navigate to the project:

cd user-insights-cli

Install dependencies:

npm install

## Run

npm start

## API

JSONPlaceholder

- Users
- Posts
- Todos
